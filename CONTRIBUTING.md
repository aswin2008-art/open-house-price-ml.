# Contributing

Thanks for considering a contribution!

1. Open an issue describing the bug or proposed improvement.
2. For substantial changes, discuss the approach before starting work.
3. Keep changes focused and explain why they are useful.
4. Run the training command and include the output when changing the model workflow.
5. Do not commit private data, API keys, credentials, or data you do not have permission to share.
6. Update the README when behavior or setup changes.

Please be respectful and constructive in discussions.
